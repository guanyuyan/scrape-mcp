## 一、项目定位

`scrape-mcp` 是一个**面向 LLM 的网页读取器（MCP Server）**：自动绕过反爬与登录墙，把任意网页精简为"极省 Token 的干净正文"，供大模型高效读取。

一句话卖点：**把任意网页变成一份极省 token 的干净正文给 AI 读，反爬、登录墙、JS 渲染自动处理，本地运行、隐私可控。**

---

## 二、核心能力（M1–M5 全链路）

| 模块 | 阶段 | 能力 |
|---|---|---|
| MCP 骨架 + `web_fetch` | M1 | L1 curl_cffi 抓取 + compact 精简输出，最短可用闭环 |
| 浏览器升级链路 | M2 | detector 判定拦截 → Playwright + Stealth 渲染，命中才升级 |
| 登录态持久化 | M3 | `login` 手动登录 + 按站点落盘，自动带 Cookie/LocalStorage |
| 缓存 / 批量 / 代理 | M4 | 磁盘缓存、`web_batch` 并发、代理支持 |
| Stealth 深度加固 | M5 | 原型清理、Canvas/WebGL 指纹、时区对齐等 |

### 关键特性
- **极省 Token**：密度选根 + DOM 剪枝 + 表格转 CSV + 外链降级 + 预算截断。实测 MDN 214KB → 数百 token（约 1% 压缩率）。
- **分级反爬**：默认 curl_cffi 指纹（快、并发好），被拦截或 JS 骨架页才升级浏览器，费用只在必要时支付。
- **如实上报**：挑战页 / 登录墙 / 骨架页一律返回 `blocked` / `report` / `note`，绝不把验证码当正文喂给模型。
- **双传输**：stdio（MCP 客户端）与 streamable-http（Postman / curl 曲线调用）均支持。
- **全配置化**：所有可调项经 `SCRAPE_MCP_*` 环境变量或项目根 `.env` 覆盖。
